# Bug修复报告和改进建议

## 已修复的Bug (6个)

### ✅ Bug #1: 重复的return语句 (CRITICAL)
**文件**: `src/parser.py:252-256`
**问题**: `_get_segment_strict()`有两个return语句，第二个永远不会执行且返回错误类型
**修复**: 删除了死代码

### ✅ Bug #2: segment_strict类型转换错误 (HIGH)
**文件**: `src/parser.py:114-116`
**问题**: 配置值被解析为float，但类型检查期望string，导致segment_strict保持为float而非boolean
**修复**: 正确处理numeric到boolean的转换

### ✅ Bug #3: 线程join超时问题 (HIGH)
**文件**: `src/player.py:98-99`
**问题**: 1秒超时后线程可能仍在运行，导致多个播放线程同时存在
**修复**: 增加超时到2秒，添加注释说明优雅处理

### ✅ Bug #4: skip_backward_notes索引越界 (HIGH)
**文件**: `src/player.py:209-212`
**问题**: 跳转到上一行时设置`_current_note = len(line)`，导致索引越界
**修复**: 改为`len(line) - 1`

### ✅ Bug #5: skip_forward_notes缺少边界检查 (HIGH)
**文件**: `src/player.py:180-195`
**问题**: `_current_line`可能超出score长度
**修复**: 添加边界检查，到达末尾时clamp到最后有效位置

### ✅ Bug #6: 配置保存重复插入 (MEDIUM)
**文件**: `src/cli.py:757-790`
**问题**: 在循环中每次都插入缺失的配置，导致重复
**修复**: 只在首次退出配置段时插入一次

## 未修复的Bug (6个)

### ⚠️ Bug #6: 琶音延音模式按键释放逻辑 (MEDIUM)
**文件**: `src/player.py:337-350`
**问题**: 在琶音中，`note.keys[idx - 1]`可能是Note对象（嵌套和弦），不是字符串
**影响**: 嵌套和弦在延音模式下可能不会正确释放
**建议修复**: 添加类型检查，处理Note对象的情况

### ⚠️ Bug #8: Curses错误被静默抑制 (MEDIUM)
**文件**: `src/cli.py:360-362`
**问题**: 所有curses错误都被忽略，可能隐藏真实问题
**影响**: 终端损坏或渲染bug难以调试
**建议修复**: 至少记录错误，或只捕获特定错误类型

### ⚠️ Bug #10: keyboard_controller pynput fallback问题 (LOW)
**文件**: `src/keyboard_controller.py:34-35, 49-50`
**问题**: pynput的`press()`期望Key对象或字符，不是字符串
**影响**: 在没有keyboard库时fallback可能失败
**建议修复**: 转换字符串为正确的Key对象

### ⚠️ Bug #11: 缺少数值参数验证 (LOW)
**文件**: `src/player.py:104-126`
**问题**: 没有验证参数是否为数值类型
**影响**: 传入非数值会导致TypeError
**建议修复**: 添加类型检查和异常处理

### ⚠️ Bug #12: 空行显示逻辑可能访问None (LOW)
**文件**: `src/cli.py:56-58`
**问题**: `self.player`可能为None时访问`_empty_line_interval_rating`
**影响**: 初始化时可能崩溃
**建议修复**: 添加None检查

### ⚠️ Bug #13: 配置文件解析不支持注释行 (LOW)
**文件**: `src/parser.py:85-94`
**问题**: 配置段中的注释行会被当作配置结束
**影响**: 无法在配置中添加注释
**建议修复**: 跳过以#开头的行
