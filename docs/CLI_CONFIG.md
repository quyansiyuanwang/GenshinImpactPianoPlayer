# CLI 配置面板使用指南

## 功能概述

CLI 模式现在包含一个实时配置面板，可以在播放过程中调整所有参数！

**特色**：
- ✅ 无闪烁显示（使用光标移动技术）
- ✅ 实时配置面板
- ✅ 流畅的视觉体验

## 技术特性

### 无闪烁显示
- 使用 ANSI 转义序列 `\033[NA` 移动光标
- 使用 `\033[J` 清除屏幕下方内容
- 不使用 `cls` 或 `clear` 命令
- 完全消除屏幕闪烁

### 更新频率
- 每 0.05 秒更新一次（20 FPS）
- 平滑流畅的播放体验

## 配置参数说明

### 1. Speed（播放速度）
- **作用**：整体播放速度倍率
- **范围**：0.1x - 3.0x
- **快捷键**：`+` 增加，`-` 减少
- **步长**：0.1x
- **示例**：
  - 1.0x = 正常速度
  - 2.0x = 快一倍
  - 0.5x = 慢一半

### 2. Arpeggio Interval（琶音间隔）
- **作用**：琶音 `[ABC]` 中每个音符之间的间隔
- **范围**：0.01s - 1.0s
- **快捷键**：`[` 减少，`]` 增加
- **步长**：0.01s
- **建议值**：0.02s - 0.05s

### 3. Note Interval（音符间隔）
- **作用**：每个音符（单音、和弦、琶音、空音）之后的间隔
- **范围**：0.01s - 5.0s
- **快捷键**：`,` (< 键) 减少，`.` (> 键) 增加
- **步长**：0.01s
- **建议值**：0.03s - 0.08s
- **重要**：这是控制播放速度的主要参数

### 4. Line Interval（换行间隔）
- **作用**：每行结束后的额外间隔倍率
- **范围**：0.0x - 5.0x
- **快捷键**：`↑` 增加，`↓` 减少
- **步长**：0.1x
- **建议值**：0.0x（通常不需要）

## 快捷键完整列表

### 播放控制
- `Space` - 播放/暂停
- `Esc` - 停止
- `Q` - 退出程序

### 速度调整
- `+` - 增加整体速度（+0.1x）
- `-` - 减少整体速度（-0.1x）

### 间隔调整
- `[` - 减少琶音间隔（-0.01s）
- `]` - 增加琶音间隔（+0.01s）
- `,` 或 `<` - 减少音符间隔（-0.01s）
- `.` 或 `>` - 增加音符间隔（+0.01s）
- `↑` - 增加换行间隔（+0.1x）
- `↓` - 减少换行间隔（-0.1x）

### 导航
- `←` - 跳转到上一行
- `→` - 跳转到下一行

## 使用技巧

### 1. 快速调整播放速度

**方法一：使用 Speed 倍率**
```
按 + 键几次，将 Speed 调到 1.5x 或 2.0x
```
- 优点：简单快速
- 缺点：所有间隔都会缩短

**方法二：调整 Note Interval**
```
按 , 键几次，将 Note Interval 从 0.10s 降到 0.03s
```
- 优点：更精确控制
- 缺点：需要多次按键

**推荐**：先用 Speed 快速调整，再用 Note Interval 微调

### 2. 调试谱面节奏

如果播放不流畅：

1. **太快**：
   - 增加 Note Interval（按 `.` 键）
   - 或减少 Speed（按 `-` 键）

2. **太慢**：
   - 减少 Note Interval（按 `,` 键）
   - 或增加 Speed（按 `+` 键）

3. **琶音太快/太慢**：
   - 调整 Arpeggio Interval（按 `[` 或 `]` 键）

### 3. 实时调整

播放过程中可以随时调整参数：
1. 开始播放
2. 观察效果
3. 按快捷键调整
4. 立即生效

### 4. 找到最佳配置

1. 从默认配置开始播放
2. 如果太慢，按 `+` 增加速度
3. 如果太快，按 `-` 减少速度
4. 微调 Note Interval 达到最佳效果
5. 记住最终的配置值
6. 修改谱面文件的配置参数

## 显示格式说明

### 音符显示
- 单音符：`Q`
- 和弦：`(QWE)`
- 琶音：`[QWE]`
- 空音（休止符）：`_`

### 颜色
- **灰色**：已弹过的行
- **红色**：当前行已弹过的音符
- **黄色加粗**：正在弹奏的音符
- **正常白色**：未弹的音符

## 示例场景

### 场景 1：谱面太慢

```
初始配置：
  Speed: 1.00x
  Note Interval: 0.100s

操作：
1. 按 + 键 5 次 → Speed: 1.50x
2. 按 , 键 5 次 → Note Interval: 0.050s

结果：播放速度提升约 3 倍
```

### 场景 2：琶音太快

```
初始配置：
  Arpeggio Interval: 0.020s

操作：
1. 按 ] 键 3 次 → Arpeggio Interval: 0.050s

结果：琶音变慢，更清晰
```

### 场景 3：需要在每行之间停顿

```
初始配置：
  Line Interval: 0.00x

操作：
1. 按 ↑ 键 5 次 → Line Interval: 0.50x

结果：每行结束后有明显停顿
```

## 常见问题

### Q: 配置面板占用太多空间？
A: 配置面板固定在底部，谱面显示窗口已优化为 3 行前 + 6 行后，总共约 10 行。

### Q: 调整后的配置会保存吗？
A: 不会自动保存。如果找到了最佳配置，需要手动修改谱面文件的配置参数。

### Q: 如何恢复默认配置？
A: 停止播放（按 `Esc`），然后重新启动程序。

### Q: 快捷键不起作用？
A:
- 确保以管理员身份运行（Windows）
- 确保安装了 `keyboard` 库
- 确保终端窗口有焦点

## 配置文件格式

找到最佳配置后，修改谱面文件：

```
1.4
ARPEGGIO_INTERVAL=0.03
INTERVAL_RATING=0.05
SPACE_INTERVAL_RATING=0
LINE_INTERVAL_RATING=0
------
```

对应 CLI 显示：
- Arpeggio Interval: 0.030s
- Note Interval: 0.050s
- Line Interval: 0.00x
