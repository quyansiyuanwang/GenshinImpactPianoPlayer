# 全谱显示功能使用指南

## 功能概述

GIPianoPlayer 现在支持全谱显示 + 实时高亮功能！

- **GUI 模式**：图形界面显示完整谱面，当前音符黄色高亮
- **CLI 模式**：终端全屏显示谱面，彩色高亮当前进度

## GUI 模式

### 启动
```bash
uv run main.py --gui
```

### 功能
1. **打开文件**：点击 "Open File" 选择谱面
2. **查看谱面**：下方文本区域显示完整谱面
3. **开始播放**：点击 "Play"
4. **实时高亮**：
   - 当前音符：黄色背景 + 加粗
   - 已弹音符：灰色
   - 未弹音符：正常黑色
5. **自动滚动**：自动滚动到当前位置

### 显示格式
```
Version: 1.4
ARPEGGIO_INTERVAL: 0.05
INTERVAL_RATING: 0.1

============================================================

(VAH) / H Q / (BSJ) / H G /
(CMG) / S / (CND) / G D /
(XS) / N A / (BG) / (XS) /
...
```

## CLI 模式

### 启动
```bash
uv run main.py "谱面文件.qymusic"
```

### 功能
1. **自动滚动显示**：只显示当前行附近的内容
   - 显示当前行前 5 行
   - 显示当前行后 10 行
   - 自动跟随播放进度滚动
2. **彩色高亮**：
   - 已弹行：灰色
   - 当前行已弹音符：红色
   - 当前弹奏音符：黄色加粗
   - 未弹音符：正常白色
3. **实时刷新**：每 0.05 秒更新一次
4. **状态栏**：显示当前状态、行数、进度

### 显示示例
```
GIPianoPlayer - Command Line Interface
======================================================================
File: 一笑江湖.qymusic
Lines: 78

    ... (20 lines above) ...

[ 21] (VAH) / H Q / (BSJ) / H G /          <- 灰色（已弹完）
[ 22] (CMG) / S / (CND) / G D /            <- 灰色（已弹完）
[ 23] (XS) / N A / (BG) / (XS) /           <- 红色 + 黄色（当前行）
     ^^^^^ ^ ^ ^   ^^^^    ^^^^
     红色  红 红 红  黄色    正常
[ 24] (VAH) / H Q / (BSJ) / H G /          <- 正常（未弹）
[ 25] (CMG) / S / (CND) / G D /            <- 正常（未弹）
...
[ 33] (XS) / N A / (BG) / (XS) /           <- 正常（未弹）

    ... (45 lines below) ...

======================================================================
Status: PLAYING | Line 23/78 | Progress: 29.5%

Controls: [Space] Play/Pause | [Esc] Stop | [+/-] Speed | [Q] Quit
```

### 滚动窗口说明
- **前 5 行**：显示已经弹过的行（灰色）
- **当前行**：高亮显示当前弹奏进度
- **后 10 行**：显示即将弹奏的行（正常颜色）
- **省略提示**：显示上方/下方还有多少行未显示

### 颜色说明
- **灰色**：已经弹过的行
- **红色**：当前行中已经弹过的音符
- **黄色加粗**：正在弹奏的音符
- **正常白色**：还没弹到的音符

## 快捷键（CLI 模式）

需要安装 `keyboard` 库并以管理员身份运行：

- `Space`：播放/暂停
- `Esc`：停止
- `+/-`：调整速度
- `[/]`：调整琶音间隔
- `↑/↓`：调整行间隔
- `←/→`：跳转到上一行/下一行
- `Q`：退出

## 测试显示

```bash
uv run python tests/test_cli_display.py "谱面文件.qymusic"
```

这会模拟播放过程，让你看到显示效果，但不会实际按键。

## 优化建议

### 终端设置（CLI 模式）
1. **使用支持 ANSI 颜色的终端**：
   - Windows：Windows Terminal（推荐）
   - macOS/Linux：默认终端即可

2. **调整终端大小**：
   - 建议至少 80 列宽
   - 高度根据谱面行数调整（建议 30+ 行）

3. **字体**：
   - 使用等宽字体（Consolas, Courier New, Monaco）
   - 字号适中，便于阅读

### 性能优化
- CLI 模式每 0.05 秒刷新一次，避免闪烁
- GUI 模式每个音符更新一次高亮
- 如果感觉卡顿，可以降低 INTERVAL_RATING

## 常见问题

### Q: CLI 模式没有颜色？
A:
- Windows：使用 Windows Terminal 或 PowerShell
- 确保终端支持 ANSI 转义序列
- 旧版 CMD 可能不支持颜色

### Q: CLI 模式闪烁太快？
A: 这是正常的，因为每个音符都会刷新屏幕。可以：
- 增加 INTERVAL_RATING（如 0.05）让播放慢一点
- 使用 GUI 模式（不会闪烁）
- 现在使用自动滚动，只显示 16 行左右，闪烁会减少

### Q: CLI 模式显示不全？
A:
- 现在使用自动滚动，只显示当前行附近的内容
- 显示窗口：前 5 行 + 当前行 + 后 10 行
- 会自动跟随播放进度滚动
- 不需要手动滚动

### Q: GUI 模式谱面显示不完整？
A:
- 调整窗口大小
- 使用滚动条查看
- 播放时会自动滚动到当前位置

### Q: 如何只查看谱面不播放？
A:
- GUI 模式：打开文件后不点 Play
- CLI 模式：使用测试脚本 `test_cli_display.py`

## 使用技巧

1. **调试谱面**：使用全谱显示可以看到哪些音符被识别
2. **学习谱面**：暂停播放，查看当前位置
3. **跳转**：CLI 模式用 ←/→ 跳转到指定行
4. **速度调整**：GUI 模式用滑块，CLI 模式用 +/-

## 示例

### 完整使用流程

1. **启动 GUI**：
   ```bash
   uv run main.py --gui
   ```

2. **打开谱面**：点击 "Open File"，选择 `.qymusic` 文件

3. **查看谱面**：在文本区域查看完整谱面

4. **调整参数**：使用滑块调整速度和间隔

5. **开始播放**：点击 "Play"，观察黄色高亮跟随

6. **实时调整**：播放过程中可以调整 Speed 滑块

7. **停止**：点击 "Stop"，高亮重置
