## 版本 1.3 - 2026-03-14

### 重要修正：空格和分隔符的含义

**修正了解析逻辑**：
- **空格是空音（休止符）**：占据一个音符位置，但不按键
- **`/` 是视觉分隔符**：用于分组对齐，不是音符，会被忽略

#### 示例

原始谱面：
```
(VQ)   /(AFH) E /(BW)   /(SGQ) W /
```

解析结果（16 个音符）：
```
(VQ) _ _ _ (AFH) _ E _ (BW) _ _ _ (SGQ) _ W _
```
（`_` 表示空音/休止符）

#### 显示格式
- CLI 模式：空音显示为 `_`
- GUI 模式：空音显示为 `_`
- `/` 不显示（被忽略）

## 版本 1.1 - 2026-03-14

### 主要改进

#### 1. 正确的播放逻辑
- **每个音符之间都有间隔**：单音、和弦、琶音、空音都算作一个音符
- **`/` 是空音**：占据一个音符位置，但不按键
- **节奏一致性**：每个音符后都等待 INTERVAL_RATING 秒（除了行尾最后一个音符）

#### 2. 实时音符显示
- **CLI 模式**：显示当前正在弹奏的音符
  ```
  [PLAYING] Line 2/78 Note 5/11 [BSJ] (2.5%)
  ```
- **GUI 模式**：状态栏显示当前音符和行数
  ```
  Playing: [BSJ] - Line 2/78
  ```

#### 3. 性能优化
- 减少和弦内部延迟（0.01s → 0.005s）
- 优化进度更新机制
- 更流畅的播放体验

### 播放逻辑示例

谱面：`(VAH) / H Q`

播放过程：
1. 同时按下 V、A、H（和弦）
2. 等待 INTERVAL_RATING 秒
3. 空音（不按键）
4. 等待 INTERVAL_RATING 秒
5. 按下 H
6. 等待 INTERVAL_RATING 秒
7. 按下 Q
8. （行尾，不等待）

### 配置建议

你的谱面 `INTERVAL_RATING=0.1` 可能太慢。建议修改为：

```
1.4
ARPEGGIO_INTERVAL=0.02
INTERVAL_RATING=0.03
SPACE_INTERVAL_RATING=0
LINE_INTERVAL_RATING=0
------
```

这样播放速度会提升约 **3 倍**！

1. **观察音符显示**：确认每个音符都被正确识别
2. **检查间隔**：如果太快或太慢，调整 INTERVAL_RATING

### 常见问题

**Q: 为什么播放还是不流畅？**

A: 检查以下几点：
1. INTERVAL_RATING 是否太大（建议 0.03-0.05）
2. 是否以管理员身份运行（keyboard 库需要）
3. 游戏窗口是否在前台
4. 尝试调整 Speed 倍率（1.5x 或 2x）

**Q: 如何知道当前弹奏到哪里了？**

A:
- CLI 模式：终端会实时显示当前音符
- GUI 模式：状态栏显示当前音符和行数

**Q: `/` 是什么意思？**

A: `/` 是空音，占据一个音符的位置但不按键。它用于控制节奏，在需要停顿的地方插入空音。
