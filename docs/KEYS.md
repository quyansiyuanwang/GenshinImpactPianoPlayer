# 按键说明

## 支持的按键

GIPianoPlayer 只支持以下按键（游戏键盘布局）：

```
Q W E R T Y U
A S D F G H J
Z X C V B N M
```

**共 21 个按键**

## 重要说明

1. **只有这些按键会被识别和输入**
   - 谱面文件中的其他字母（如 I, K, L, O, P 等）会被自动忽略
   - 所有按键会自动转换为大写

2. **谱面文件格式**
   ```
   # 配置参数
   1.4
   ARPEGGIO_INTERVAL=0.05
   INTERVAL_RATING=0.1
   SPACE_INTERVAL_RATING=1
   LINE_INTERVAL_RATING=0
   ------

   # 谱面内容
   (VAH)   /H Q /(BSJ)   /H G /
   (CMG)   /S   /(CND)   /G D /
   ```

3. **符号说明**
   - `Q` - 单个按键
   - `(QWE)` - 和弦（同时按下 Q、W、E）
   - `[QWE]` - 琶音（快速依次按下 Q、W、E）
   - `[(QW)E]` - 混合（先同时按 Q、W，然后按 E）
   - `/` - 空格间隔标记

4. **无效字符处理**
   - 谱面中的无效字符（如 I、K、L、O、P 等）会被自动过滤
   - 不会影响程序运行
   - 只会输入有效的 21 个按键

## 示例

### 原始谱面（可能包含无效字符）
```
(VAHI)   /H Q /(BSJK)   /H G /
```

### 实际输入（过滤后）
```
(VAH)   /H Q /(BSJ)   /H G /
```
- `I` 和 `K` 被自动忽略

## 使用建议

1. **创建谱面时**：尽量只使用有效的 21 个按键
2. **导入现有谱面**：程序会自动过滤无效字符，无需手动修改
3. **测试谱面**：使用 GUI 模式可以实时查看哪些按键被识别

## 键盘布局参考

```
┌─────────────────────────────┐
│  Q  W  E  R  T  Y  U        │
│   A  S  D  F  G  H  J       │
│    Z  X  C  V  B  N  M      │
└─────────────────────────────┘
```

这是标准的游戏键盘布局，覆盖了左手和部分右手区域。
